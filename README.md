# Ames Housing Price Prediction – Machine Learning Project

## OBJECTIVE

The main objective of this project is to predict house sale prices based on different property features such as living area, lot area, overall quality, number of rooms, and other housing characteristics.

This project helps understand how different factors influence house prices using Machine Learning techniques.

## DATASET

- **Dataset Name:** Ames Housing Dataset
- **Source:** https://www.kaggle.com/code/hnazari8665/ames-housing-dataset
- **Rows:** 2,9000
- **Columns:** 82 (original training dataset)

**Key Features:**
- LotArea – Lot size of the property
- OverallQual – Overall material and finish quality
- GrLivArea – Above-ground living area
- BedroomAbvGr – Number of bedrooms
- FullBath – Number of full bathrooms
- YearBuilt – Year the house was built
- SalePrice – Target variable to be predicted

## KEY INSIGHTS

- House prices are influenced by several property characteristics.
- Overall quality plays an important role in determining house prices.
- Larger living areas generally tend to have higher sale prices.
- Lot area provides additional information about property size.
- The year a house was built can influence its market value.
- Categorical features need to be encoded before using them in Machine Learning models.
- Data preprocessing is an important step in building an accurate prediction model.
